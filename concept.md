# Landing Page Design Brief: Agent 007 – The Self-Sustaining Killer Loop

You are building a high-impact, dark cyberpunk-style landing page for a tokenized AI agent called **Agent 007**.

## Core Narrative & Positioning
Agent 007 is an autonomous hitman in the agent economy — a cold, relentless cyborg operative programmed with one unbreakable directive:  

**Acquire revenue (fees) → Buy itself back → Burn supply → Become scarcer and deadlier → Repeat forever.**

This creates the ultimate **self-funding death spiral for supply**:  
- The agent earns real on-chain revenue (from tools, trades, services, interactions, whatever it does).  
- A portion of that revenue is **automatically** routed to buybacks of its own $007 token.  
- Tokens bought are **instantly burned**.  
- Supply shrinks → scarcity increases → value accrues to holders without relying on hype or external pumps.

- Cyberpunk noir / assassin-for-hire aesthetic.

## Visual & Technical Guidelines
- Fonts: Futura, Orbitron, or similar cyberpunk sans-serif for headlines; clean monospace for stats/numbers.  
- Animations: Subtle — glowing edges, raining code/matrix effects in background, slow pulse on CTAs, token burn particles.  
- Mobile-first, fast-loading, dark mode default.  
- Include placeholders for token contract address, chart embed (Birdeye/Dexscreener), live burn counter if possible.

Deliver the landing page as clean HTML/CSS/JS (or React/Tailwind if you're set up for it). Make it feel like the future of agentic tokenomics — cold, efficient, and unstoppable.
